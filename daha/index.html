파일 받기

01바로 쓰는 프롬프트 틀

[ ] 부분만 내 업무로 바꿔서 사용. 마지막 줄은 실적보고 · 공문에 항상 붙이기.

실습 ① 이용 어르신 가을철 안전 안내문 (ChatGPT)

  1. 자유롭게 한 줄: "가을 안전 안내문 써줘"
  2. 위 틀의 빈칸을 채워 다시 입력 → 결과 비교
  3. 이어서 "70대가 읽기 쉽게, 한 문장 20자"
  4. 이어서 "보호자 문자 80자로 줄여줘"

02Gemini 요청 사항

설정 → 개인 인텔리전스 → 요청 사항 → [+ 추가]에 붙여넣기. ①은 기본, ②·③은 업무에 맞게 추가.

03Canvas 5가지 실습

입력창 [+] → Canvas 선택 후 프롬프트 붙여넣기. ②는 Canvas 실습자료 엑셀을 먼저 올리기.

04Gemini 스킬 12개

설정 → 스킬 → [수동으로 만들기]에 이름 · 설명 · 요청 사항을 하나씩 붙여넣고 [만들기]. 새 채팅에서 / 입력 후 스킬을 골라 테스트 메모로 확인.

05Gemini Notebook 요청 예시

공개 지침 · 매뉴얼만 넣기. 이용자 명단 · 상담 기록은 넣지 않음.

06이미지 · 포스터 프롬프트

그림에는 글자를 넣지 않게 하고, 실제 글자는 PPT · 한글에서 넣는 것이 가장 안정적.

07실습 내내 지킬 것

  • 개인정보 넣지 않기이용자 이름 · 연락처 · 주소 · 건강 · 상담 내용 원문은 어떤 AI에도 넣지 않음. A씨, 30대처럼 바꿔서.
  • 숫자는 원본과 대조금액 · 날짜 · 인원 · 기준은 지침 원문과 엑셀 원본으로 한 번 더 확인.
  • 결과물은 초안최종 책임은 담당자. 근거 없는 수치 · 과장 표현은 지우고 사용.
  • 실습 자료는 모두 가상파일 속 기관 실적 · 메모 · 응답은 실습용으로 지어낸 내용.

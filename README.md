# 연차대장 계산기

휴무 관리 업무 매뉴얼(연차·장기근속휴가)의 계산 규칙을 그대로 옮긴 단일 HTML 계산기입니다.
입사일 하나로 **연차대장 · 퇴직정산 · 연차촉진 일정 · 단축근로 80% 비례**를 산출합니다.

## 사용

`index.html` 을 브라우저로 열면 됩니다. 빌드나 서버가 필요 없고, 외부 요청은 웹폰트뿐입니다.

## 계산 규칙

### 연차 발생 (회계연도 기준 · 비례-15-15-16)

입사 첫해를 근속년수에 포함하지 않는 센터 적용 방식입니다.

| 근무년차 | 부여 시점 | 일수 |
|---|---|---|
| 1년차 미만 | 입사일 + n개월 (n = 1~11), 매월 만근 시 | 1일씩 |
| 2년차 | 이듬해 1월 1일 | `15 × (13 − 입사월) / 12` (비례) |
| 2년차 월차 | 최초 1년 도달 전까지 | 잔여분 (월차 합계 최대 11일) |
| 3 ~ 4년차 | 매년 1월 1일 | 15일 |
| 5년차 이상 | 매년 1월 1일 | `15 + ⌊(근무년차 − 3) / 2⌋`, 상한 25일 |

소수점은 주간근로자 **반일단위 올림**, 교대근무자·단축근로자는 **시간단위**로 표시합니다.

### 퇴직정산

```
차이     = 회계연도 기준 총 발생 − 입사일 기준 총 발생
조정부여 = 올해 부여 연차 − 차이
정산     = 조정부여 − 올해 사용 연차      (음수면 급여 환수)
```

### 연차촉진

- **1년 이상**: 1차 7/1~7/10 → 계획서 ~7/20 → 2차 ~10/31
- **1년 미만**: 최초 1년 종료일 `E = 입사일 + 1년 − 1일` 을 기준으로,
  촉구 기준일 `E − 3개월 + 1일` 이전 발생분과 그 이후 발생분을 각각 따로 촉진합니다.

> 매뉴얼 본문은 나머지 발생분의 2차 촉진 기한을 '1개월 전'으로 적고 있으나,
> 근로기준법 제61조제2항제2호 단서는 **10일 전**까지로 규정합니다. 계산기는 법 조문을 따릅니다.

### 단축근로 80%

단축근로 일수가 소정근로일의 20%를 넘으면 시간 비례로 계산합니다.

```
연차시간 = 연차 × (단축일수 / 소정근로일) × 단축시간
         + 연차 × (정상일수 / 소정근로일) × 정상시간
```

## 테스트

```
node calc.test.js
```

`index.html` 안의 순수 계산 함수 블록을 그대로 추출해 실행하므로, 배포 코드와 테스트 대상이 항상 같습니다.
매뉴얼에 실린 예시(4쪽 연차 계산 표, 5쪽 퇴직정산 예시 1·2, 상황 1~3, 2~3쪽 촉진 일정)를 모두 검증합니다.
